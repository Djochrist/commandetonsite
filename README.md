**Créé par Djochrist K.**

## Qu'est-ce que c'est ?

CommandeTonSite est une vitrine web professionnelle qui présente 10 demos de sites internet pour différents secteurs d'activité.

Chaque page est une démonstration complète et réaliste d'un site web pour un type de business. Le but est de montrer aux entrepreneurs et commerçants de Lubumbashi ce qu'un site web professionnel peut faire pour leur activité, afin qu'ils puissent commander leur propre version personnalisée.

---

## Les 10 secteurs couverts

| Secteur | Description |
|---------|-------------|
| Accueil | Hub central présentant tous les demos |
| Influenceur | Portfolio, media kit et prise de contact sponsors |
| Informatique | Agence tech, startup et services digitaux |
| Automobile | Concessionnaire, garage et vente de véhicules |
| Santé | Clinique, cabinet médical et services de santé |
| Mode | Boutique, créateur de mode et showroom |
| Restaurant | Menu en ligne, réservations et takeaway |
| Supermarché | Grande surface, alimentation et promotions |
| École | Établissement scolaire, formations et inscriptions |
| Salon de coiffure | Salon de beauté, galerie et réservation en ligne |
| Boutique en ligne | E-commerce, catalogue produits et commande WhatsApp |

## Comment lancer l'application

### Prérequis
- **Node.js** version 18 ou plus → [Télécharger ici](https://nodejs.org)
- npm (inclus avec Node.js)

### Sur Windows
Double-cliquez sur **`start.bat`**

### Sur Mac / Linux
```bash
chmod +x start.sh
./start.sh
```

### Manuellement
```bash
cp package.standalone.json package.json
npm install
npm run dev
```

L'application s'ouvre sur **http://localhost:3000**

## Technologies utilisées

- **React 19** - interface utilisateur
- **TypeScript** - typage statique
- **Vite** - build tool ultra-rapide
- **Tailwind CSS v4** - styles utilitaires
- **Framer Motion** - animations
- **Wouter** - routeur léger côté client
